## 支持情况

- 目标 API 版本：26.0.0(26)
- 兼容 API 版本：6.0.0(20)
- Flutter 版本：3.41.10-ohos

## 功能适配情况

**🎉鸿蒙端所有功能都已与上游同步🎉**

- [x] 视频解析器
- [x] 手势亮度调节
- [x] 手势系统音量调节
- [x] 智慧多窗
- [x] 鸿蒙 PC
- [x] 基于 mpv 的视频播放器
- [x] ech 支持 ([@tignioj](https://github.com/tignioj))
- [x] 硬件解码
- [x] 外部播放器
